## English

First public release of ANMP, the message format and client core of anynear. The protocol version is v1; the library
version starts at 0.9.0.

### Specification
- `spec/anmp.md` and `spec/anmp.cddl` describe protocol version v1 as the anynear apps use it.
- New section "Security considerations": goals, limits (no forward secrecy, the invitation link is the circle secret, weaker sender proof over radio, random nonces under long-lived keys) and what relays, radio listeners and push services see.
- Header field 8 (`askTags`) is reserved: a v1 `ask` does not carry it, readers still parse it.
- The example of the radio list uses an invented community.

### Libraries
- Kotlin Multiplatform: `format` (packets, encryption, signatures, key derivation; no dependencies) and `core` (circles, contacts, mailboxes, sending and fetching on ANDP).
- Go: the radio part of the format.
- Test vectors in `vectors/`; Kotlin writes them, Go checks them.

### Compatibility
- Version v1 constants never change. An incompatible change will be `anmp/v2` next to v1.
- The Kotlin core needs ANDP 0.9.0 checked out next to this repository.
- Not independently audited.
