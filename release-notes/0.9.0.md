## English

First public release of ANMP, the message format and client core of anynear. The protocol version is v1; the library
version starts at 0.9.0.

### Specification
- `spec/anmp.md` and `spec/anmp.cddl` describe protocol version v1 as the anynear apps use it.
- New section "Security considerations": goals, limits (no forward secrecy, the invitation link is the circle secret, weaker sender proof over radio, random nonces under long-lived keys) and what relays, radio listeners and push services see.
- Header field 8 (`askTags`) is reserved: a v1 `ask` does not carry it, readers still parse it.
- The example of the radio list uses an invented community.
- Everything to a person goes once to its mailbox recipient (field 7 of the device list) instead of once per device; every device of the person reads it, also one back from the emergency card.
- Packets to a person's mailbox recipient carry no signature: the pair key proves the sending device, which must be listed with exactly its keys in the sender's chain. Signatures stay where many share a key.
- Over radio, direct packets go to the person as well: route tag and pair key of its mailbox recipient, taken by every device of the person in range; pickups include the person.
- Content field 37 `author`: own copies of received direct packets name their author. Packets heard only over radio and, once after the update, the old per-device entries of the own mailbox are written as such copies, so every own device and the emergency card get them.
- Device entry field 5 `moved`: a device notes in the device list that it moved its old entries and history to the person.
- New "Device space": settings of each own device, so that a phone replacing another one can take them over.

### Libraries
- Kotlin Multiplatform: `format` (packets, encryption, signatures, key derivation; no dependencies) and `core` (circles, contacts, mailboxes, sending and fetching on ANDP).
- `pendingEmergencyCard()`: the code of an emergency card made but not yet confirmed, so the app can show it again instead of making a new card.
- Go: the radio part of the format.
- `core`: in a circle history, messages of a removed device stay with their person if they were written before it was removed (`personOfDevice` for messages an app already keeps).
- `core`: a contact whose mailbox refuses every direct message with 403 (for example after the person deleted everything) is marked unreachable until something of the person arrives again.
- `core`: `undeliveredWrites()` counts writes no relay has yet; deleting everything waits for those instead of for every holder.
- Test vectors in `vectors/`; Kotlin writes them, Go checks them.

### Compatibility
- Version v1 constants never change. An incompatible change will be `anmp/v2` next to v1.
- The Kotlin core needs ANDP 0.9.0 checked out next to this repository.
